## Free Hosting on GitHub Pages (5 minutes)

### Step 1 — Create the repository

1. Go to [github.com/new](https://github.com/new)
2. Name it **`portfolio`** (or `YOUR_USERNAME.github.io` for a root URL)
3. Set visibility to **Public**
4. Click **Create repository**

### Step 2 — Push the files

Open a terminal in this `portfolio/` folder and run:

```bash
git init
git add .
git commit -m "Initial portfolio upload"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
git push -u origin main
```

### Step 3 — Enable GitHub Pages

1. In your repo, go to **Settings → Pages**
2. Under **Source**, select branch: `main`, folder: `/ (root)`
3. Click **Save**
4. Wait ~60 seconds

Your site will be live at:
- `https://YOUR_USERNAME.github.io/portfolio/` (if named `portfolio`)
- `https://YOUR_USERNAME.github.io/` (if named `YOUR_USERNAME.github.io`)

> **Tip:** Name the repo `parthlashkari.github.io` for the cleanest URL.

## Customization tips

### Add your real GitHub link
Update `https://github.com/parthlashkari` to your actual GitHub profile URL in all portfolio files.

### Add a real project GitHub link
In the "Projects" section of each portfolio, update the `#` links to point to actual GitHub repos when you create them.

### Add a profile photo
In `minimal.html` or `creative.html`, you can add an `<img>` tag in the hero section:
```html
<img src="photo.jpg" alt="Parth Lashkari" style="width:200px; height:200px; border-radius:50%; object-fit:cover;">
```
Place your photo (`photo.jpg`) in the same `portfolio/` folder.

### Update the year
The footer says "2025" — update to current year if needed.
